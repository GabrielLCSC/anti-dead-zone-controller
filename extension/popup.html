Controller fix

The site ignores the right stick below 18%, then squares the remaining speed. At 25% deflection almost nothing is left. This fix rewrites the axes before the game reads them.

Triggers

The site only arms aim and fire from 55% of the trigger. Lowering this slider makes them active sooner. 55% changes nothing.
